The public copies retain the original encoded image pixels. EXIF, XMP, IPTC, comments, embedded thumbnails, and other application metadata were removed. A minimal orientation tag and standard image/color interpretation data were retained so the photos display correctly. No location, capture timestamp, or camera/device identifiers are retained.

No screen content, components, enclosure features, or backgrounds were synthesized or retouched. The original files remain outside the repository.
